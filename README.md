# IRPGO-LIO

Official repository of:

"IRPGO-LIO: A LiDAR-Inertial Odometry with Improved Residual Module and Pose-Graph Optimization"

## Overview

IRPGO-LIO is a tightly-coupled LiDAR-inertial odometry framework that integrates:

- Robust point cloud undistortion based on IMU prior-state interpolation
- Structure-aware adaptive residual modeling
- Adaptive measurement covariance estimation
- Scan Context based loop closure detection
- Pose graph optimization for global drift correction
